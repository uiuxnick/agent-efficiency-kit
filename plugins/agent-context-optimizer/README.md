# Agent Context Optimizer

Claude Code plugin for production-oriented context management, task scoping, persistent project memory, bounded verification, and compact handoffs.

Install through the `agent-context-tools` marketplace:

```text
/plugin marketplace add uiuxnick/agent-efficiency-kit
/plugin install agent-context-optimizer@agent-context-tools
```

Then use `/agent-context-optimizer:production-context-discipline` when a task needs explicit planning, minimal file discovery, focused verification, or a resumable handoff.
